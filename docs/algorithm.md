# 算法、精度与统计

## 连续时间 direct SSA

对于当前状态 x 的有限事件集，计算 A = sum(a_i)。若 A=0，状态吸收。否则取两个独立的开区间均匀数，等待时间 dt=-log(u1)/A，以 u2*A 在累计速率中选中一个事件，更新状态与时间。相同终态但物理通道不同的事件仍可分别列出。事件使状态保持不变也合法，例如周期单胞跨界后的索引不变而展开位移增加。

核心每步重新计算所有速率，无过期缓存或依赖图维护要求。成本为 O(M)+用户速率/动作计算成本，额外工作内存 O(M)。反应网络的组合数另有化学计量阶数循环成本。跨语言固定事件顺序、求和顺序、抽样顺序。

这精确采样状态依赖、事件间恒定速率的 Markov 跳跃过程（在数值与随机采样误差内）。它不是固定时间步 Monte Carlo，也不把选中事件的 1/a_i 当作等待时间。一次事件后的动力学可改变所有速率。

## 时间窗口与续跑

`until` 为绝对时间，须 >= 当前时间；默认无穷。先抽等待时间，若下一事件晚于 until，则只推进到 until，不执行事件，也不抽选择事件的随机数。恰好等于 until 的事件被执行。有限窗口内吸收的轨迹仍保持原状态观测到 until。

`run` 总输出初始记录；每个事件后输出记录；若时间截止或吸收将时间推进到窗口末端，增加 `event=-1` 的终端观测。末端观测的 step 不增加。`max_steps=0` 不推进时间；达到步数上限也不擅自延长到 until。

可以在时间窗口结束后继续：由于指数分布无记忆性，重抽等待时间在分布上正确。但是当前实现不保留被截断的候选事件，因此分段调用与整段调用**不保证同 seed 逐轨迹相同**。没有通用 checkpoint 序列化。模型、RNG、时间和 pending event 的持久化是未来功能。

分段常数外部条件可以在准确运行到边界后更新模型参数并继续，且必须先检查没有因 step_limit 提前退出。连续时变速率不能只在事件时重新计算，需要积分 hazard、thinning 或其他专门方法；非指数驻留时间同样不在当前算法范围内。

## 随机数

参考流为 MINSTD：s0=(seed mod 2147483646)+1；s_next=48271*s mod 2147483647；u=s/2147483647。用 64 位整数运算避免有符号溢出。seed 接受 0..2^53-1，并非每个 seed 都映射到独立流。每个已执行事件消耗两个随机数。

这个流用于方便四语言回归，周期 2147483646、约 31 位分辨率，有线性相关与尾部截断限制。不能据此宣称密码安全、并行流独立或无限长科学采样可靠。生产模拟请使用各语言 RNG 扩展点接入合适随机源。统计测试的多轨迹共享一个连续流，不把相邻 seed 当成独立随机流。

## 数值策略

浮点使用 binary64；图/反应文件中的非负整数限制在 0..2^53-1，以避免各语言转换到浮点时丢失精度。此限制属于内置适配器与计数参数，不限制自定义状态类型。

拒绝负数/非有限速率及总速率溢出。时间增量必须能使累计时间严格增加并保持有限；否则报错。极端大小的速率导致的 underflow、分辨率损失可能使小速率在顺序求和中消失，这时应重新选择时间单位、使用更高精度或更合适算法。物理速率指数很小时允许下溢到 0；极端参数导致非有限结果则拒绝。

跨语言事件/状态应完全一致，浮点轨迹使用相对容差 3e-13 核对；不承诺不同平台的 libm 逐位一致。在累计概率分界极近时也可能发生不同选中事件。

## 统计检查与单位

内核不固定单位：所有速率必须使用同一时间单位的倒数。内置材料速率函数使用 eV、K，输出 s^-1；图例子位移使用 m。

- 两态链 0->1 速率 2、1->0 速率 1，长期时间占据概率 P1=2/3。按事件数平均会错误得到约 1/2。
- 对称一维随机游走每方向速率 k，步长 a，在固定时间 t 的方差为 2*k*a²*t。D=var/(2t)，有漂移时必须减均值。
- 常数出生 b、每粒子死亡 d，初始为 0，则 E[N(t)]=(b/d)*(1-exp(-d*t))。
- 通用排队示例是 M/M/1：到达率 2，服务率 3；空队列时服务被禁用。Ising 示例使用每个自旋的连续时间 Metropolis 翻转率 exp(-max(beta*DeltaE,0))，基础尝试频率取 1。

测试同时检查等待时间均值/方差、分支概率、时间平均、守恒量和跨语言一致性。模型物理正确性仍需要针对具体应用选择验证基准。
