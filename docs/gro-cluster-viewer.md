# 独立 GRO 簇查看器

`scripts/view_clusters.py` 是单文件脚本，内嵌网页，只需 NumPy；可以单独复制到其他目录使用，不需要安装 cube 或量化计算软件。

在仓库目录运行：

```bash
uv run scripts/view_clusters.py ../anneal_a_fix.gro --cutoff 6 --molecule 85 --open
```

`uv` 自动安装脚本声明的依赖。终端输出本地 URL，浏览器打开该地址；`--open` 可省略。服务仅监听 `127.0.0.1`，关闭终端或按 Ctrl+C 停止；页面和坐标均在本机，不依赖外部网页库/CDN。

## 界面

- 下拉框选择中央分子。
- 滑块或数值框修改阈值，单位 Å；默认可调范围 0–30 Å，可用 `--max-cutoff 40` 修改上限。0 只显示中央分子。
- 拖动旋转，滚轮缩放，Shift＋拖动平移；支持自动适配及重置视角。大簇操作时自动使用外围原子点预览，中央分子保持完整，停止操作后恢复全部化学键和原子。
- “完整环境”显示当前阈值内全部完整邻居；“最近 4 个邻居”只改变显示数量。
- “显示氢”只改变绘图，筛选始终包含氢。
- 悬停原子可查看分子内序号、GRO 原子记录序号/原子编号及周期镜像。
- “导出簇 XYZ”导出当前中央分子与阈值对应的**全部原子**，中央分子在前，邻居按最短距离排序。导出不受最近四邻居或隐藏氢影响。

筛选条件是中央完整分子与候选完整分子之间，**所有原子对的最短距离严格小于阈值**，不使用 core。邻居入选后整体保留；簇外缘因此可以超过阈值。周期模式包含满足条件的完整分子镜像，包括中央分子的其他周期副本，排除中央零镜像。界面中的 `image [a,b,c]` 对应对还原后的分子整体施加 `a*A + b*B + c*C` 平移，A/B/C 是 GRO 盒矢量。

## 分子识别与周期边界

仅提供 GRO 时，按连续残基记录分组，**假设一个残基就是一个完整分子**。编号是文件中分子出现顺序，从 1 开始，旁边同时显示原始残基标签；GRO 残基号回绕时不把它当作唯一键。当前 anneal_a 体系的 100 个残基对应 100 个分子。

GRO 不保存成键拓扑。默认用周期最短距离生成树还原完整分子，按原子名推断元素、按共价半径推断显示键。这适合当前单残基小分子；对于跨多个残基的聚合物、蛋白、歧义原子名称或复杂拓扑，应提供匹配的 TPR：

```bash
uv run --with MDAnalysis scripts/view_clusters.py ../anneal_a_fix.gro \
  --tpr ../anneal_a.tpr --cutoff 6 --molecule 85 --open
```

TPR 模式按真实键拓扑片段识别分子、还原周期结构，并使用真实键和元素。会核对 TPR/GRO 原子数、名称和残基顺序。跨周期无限延伸、无法还原为有限完整分子的网络会报错。查看器仅显示几何，不生成 QM/MM 电荷或力场参数。

GRO 坐标从 nm 转为 Å；支持标准 3/9 数盒子、速度列和可变坐标精度。使用输入的**单帧 GRO 坐标**，不读取 XTC。零盒子自动采用非周期模式，`--no-pbc` 可明确关闭周期处理。单个文件连接多个 GRO 帧时会报错，请先导出所需单帧。

大簇预览在可见原子数超过 4000 时启用，外围均匀抽样至多 12000 个点；松开拖动或滚轮停止约 140 ms 后恢复完整视图。侧栏计数、阈值和 XYZ 导出始终对应完整簇。线框按环境、中央分子顺序绘制，以突出中央分子，不表示实体遮挡。[性能验证](../runs/gro_viewer_rendering_2026-11-08/README.md)。

其他选项可用 `--help` 查看。需要固定地址时使用 `--port 34416`；默认自动选择空闲端口。首次选择中央分子会计算最大阈值内的候选镜像，后续阈值调整复用缓存。
