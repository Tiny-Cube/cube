# 通用 KMC 设计

范围：四种独立实现，共享算法契约和内置模型文件格式。用户明确要求可用于任意适合 KMC 的问题，输运和反应只作为应用例子。设计选择是通用事件接口；相比仅实现电荷跳跃，它允许自定义状态、动态反应和晶格规则；相比复刻整个 VOTCA，它避免量化计算与分子映射依赖。

内核必需接口仅 model.propensities / fire；state / position 是可选观测。状态可以是任意用户对象，提供事件回调适配器，允许每步动态生成事件。速率可依赖当前状态，但在两次事件之间须恒定。每步重新计算全部速率，按固定事件顺序顺序求和；等待时间 -log(u1)/sum(a)，第二个随机数按累计速率选择事件。算法 O(M)，优先可验证的参考实现。后续可引入依赖图/Fenwick tree。

内置单粒子有向图与质量作用反应网络。图边携带三维位移，允许周期自环、多重边和吸收态；反应使用随机速率常数及组合数约定。单位 eV、K、s、m。提供 Marcus、Arrhenius、Miller–Abrahams 函数。

Python Protocol、C++ 抽象类、Rust trait、Fortran 抽象派生类型形成对应扩展点。每个版本均有库、内置适配器命令行和测试；任意模型通过库接入，以排队系统、动态任务目录和 Ising 模型验证通用性。标准文本格式 KMC1 不要求第三方解析库。轨迹 CSV 包含初态、每次跳跃后状态，以及有限时间窗口的末端观测；末端观测不是事件。

统一 MINSTD 随机流便于跨语言回归；库允许替换 uniform 来源。浮点时间只要求容差内相同，不承诺所有平台逐位相同。显式拒绝负/非有限速率、非法索引、维度不符、整数/浮点溢出及无法推进时间。零总速率正常吸收，时间截断不执行超出窗口事件。

验收：uv 构建 wheel/sdist；原生编译测试；跨语言图/反应逐事件比对；指数等待分布、分支概率、两态占据概率、反应守恒、固定时间扩散与出生死亡解析检验。范围不包含 VOTCA 数据库直接兼容、量化计算、长程库仑、自适应连续时间速率和 GPU/MPI。
