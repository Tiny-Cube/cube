# GPU 转移积分实现与验收

本轮用户明确要求实现、在指定 GPU 服务器验证、验证正常后创建 Git 分支并推送。沿用已有通用 KMC；电子结构功能为可选依赖，不改变核心所需依赖。服务器登录凭据不写入代码、文档或 Git。

## 方法与边界

1. `dipro`：中性闭壳层单体 SCF 轨道，投影收敛二聚体 Fock/KS 算符，再对片段态作对称 Löwdin 正交化。采用完整二聚体 AO 基，不作截断的二聚体 MO 展开。
2. `frozen_density`：同一组单体轨道，以两单体密度矩阵的块对角和构造一次二聚体 Fock/KS 算符，不作二聚体密度自洽。明确标为中性片段密度近似；不将它与先正交化全部占据态后构造的 Slater 行列式混同，不能误称已经实现所有 FO-DFT 变体。
3. `esid`：对称、等位点、孤立两态近似下的二聚体轨道半劈裂。要求显式承认等价片段假设，并检查投影位点能、前线态子空间权重；非适用情况输出原因，不能悄悄给一个耦合数值。
4. `orbital_gmh`：在所选两条 KS/HF 轨道的能量与电子位置偶极矩阵上应用二态 GMH。明确这是单电子轨道近似，不能冒充多电子绝热态 GMH。独立代数函数可接受真正的两态偶极和能量。

代码旁列出 DOI、公式/章节及经过核对的短原文摘句。理论文档说明原始多电子定义、单粒子近似与局域轨道相位。不同方法不要求一般情况下数值相等。

## 数据与执行

输入为两个冻结构型的 XYZ 文件或 Python 原子列表，以及显式基组、HF/DFT 泛函、精度、CPU/GPU 后端。首个实现支持中性闭壳层分子；不支持的状态明确拒绝。基组在单体与二聚体间保持一致，按原子/AO 顺序核验映射。前线近简并轨道构成子空间，返回耦合块，不强制压成一个耦合。

GPU 后端要求实际 GPU4PySCF/CuPy 对象；SCF、Fock 与投影运算在 GPU 执行，小结果转回主机输出。GPU 请求失败不静默转 CPU。CPU 使用同样的密度拟合和数值设置作为参考。SCF 未收敛时不输出伪有效转移积分。

输出 JSON 包含输入哈希/几何、方法、原始与正交化矩阵、eV/meV、所选轨道、近简并信息、各方法状态及适用性、SCF 收敛、后端/依赖版本和同步墙钟时间。

## 验收

- 数学：非正交两态解析式、能量原点平移不变、轨道相位/置换不变、奇异重叠拒绝；GMH 从已知局域两态的旋转恢复耦合，验证原点与空间旋转不变性；半劈裂的异质体系拒绝。
- 量化：乙烯同质二聚体的空穴和电子；变形/异质几何；不同间距；多轨道子空间；HF 与 DFT。比较相同 Hamiltonian 的 CPU/GPU 能量、|V| 和矩阵不变量，并核对完整 MO 投影重建。
- GPU 服务器：用 uv 的独立项目环境与锁文件，记录真实 GPU 名称、驱动、CuPy/GPU4PySCF/CUDA 版本及检查结果，不存储密码。
- 工程：已有 KMC 回归、CLI、可选依赖、wheel/sdist；校验发行物不含外部源码、环境或凭据。验收后创建新的 Git 分支、提交并推送，不把未通过测试的结果宣传为已验证。
