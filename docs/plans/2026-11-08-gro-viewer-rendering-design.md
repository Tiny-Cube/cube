# 大簇交互绘制优化

用户反馈阈值增大后旋转卡顿。当前每帧重新生成可见掩码、求包围半径，给全部原子/键建立对象并深度排序，且每条键/每个原子独立 stroke/fill。

保持单文件、离线、NumPy 依赖和全部原子/镜像数据。采用缓存分组和连续坐标缓冲，每次数据/显示选项改变时才重建可见集合与半径；每帧仅投影当前绘制集合。按中央/环境、氢/重原子分组批量绘制，去除原语对象分配和全场排序。中央分子最后绘制以持续突出，邻居统一灰蓝色；这是线框示意，不是实体遮挡渲染。

大簇（可见原子超过 4000）在拖动/连续滚轮时采用简化预览：保留中央全部可见原子和化学键，外围只画至多 12000 个均匀抽样原子点。松开或滚轮停止 140 ms 后立即恢复全部可见原子与键。降低交互时像素比到 1，静止恢复设备像素比（最高 2）。界面明确提示预览状态；预览不改数据、筛选、计数含义或导出。

鼠标移动只在每个动画帧做一次悬停命中，离开时取消；失去捕获或取消拖动也恢复完整图。测试用实际结构对比原/新渲染 JS 的准备与绘图命令数，不把模拟 Canvas CPU 时间当真实浏览器 FPS。浏览器核对大阈值完整/预览/恢复状态、邻居颜色和导出链接，并记录实际 draw 耗时用于诊断。
