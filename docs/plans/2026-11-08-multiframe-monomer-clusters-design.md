# 多帧单体、二聚体与冻结 MM 簇提取

用户要求将 `$get_dimer` 改为 `$get_dimers_monomers`，以 `dimers_cutoff` 控制 core 距离，增加 `frame_step` 和 `monomers-qmmm-cutoff`，在 monomers 中同时保存单分子及其邻域簇。用户确认空的 `monomers-qmmm-cutoff` 默认为 12 Å。

## 控制与选帧

`frame = -1` 只选最后一帧；非负 frame 是起始帧，按正整数 frame_step（默认 1）一直抽样到轨迹末尾，不强行追加未落在步长上的最后一帧。帧号从 0 开始，目录至少四位补零。保留旧段名、cutoff 和 CLI 选择名作为语法别名，统一归一化成新字段；重复别名拒绝。

每帧保留 cube-dimers-1 manifest，单帧调用仍返回该清单；多帧调用返回 cube-frames-1 的 frames.json，记录各帧相对清单路径及 SHA256。原 MD 文件只在提取开始时读取哈希一次，每帧按当前盒子和坐标单独还原完整分子、生成接触及环境。

## 环境簇

复用既有冻结 MM 整分子周期镜像选择函数，按中央完整 QM 分子与周围完整分子的最短距离严格小于 cutoff 入选，排除中央零平移副本。与 dimer core 原子判据互相独立。每个单体输出 `{id}.xyz/gjf`、`{id}_cluster.xyz/gjf`、`{id}_mm.pc` 和 `{id}_cluster.json`，按 format 决定 XYZ/GJF。

簇 XYZ 中先写中央 QM 原子，再写完整 MM 分子。簇 GJF 写中央 QM 原子及冻结 MM 外部点电荷，明确仅为静电嵌入单点模板，不包含 LJ 或优化；不会将整个 MM 簇作为 QM 体系。JSON 记录元素、完整坐标、电荷、QM/MM 划分、原全局原子索引与周期镜像，PC 与单体处于同一坐标框架。无邻居时允许结构提取产生空壳层；实际 QM/MM 仍拒绝空环境。

四点法的 mm-cutoff 未显式设置时继承提取 cutoff；独立调用默认为 12 Å。四点法仍从经过哈希核对的原帧构造环境，使用共用选择函数并可绑定原 TPR LJ，不把几何簇直接当作量化输入。提取增加的分子标签不改变既有计算环境的指纹。

## 调度、续算与验证

多帧量化遍历每帧清单；默认结果在各自帧内，显式输出目录加 frame 子目录。单体缓存仅按实际 SCF 配置、几何和输出位置识别，避免因每阶段的非物理控制字段不同而重复计算。帧集合检查路径、唯一帧号及子清单哈希。帧输出先写临时目录再原子替换，清单仅在帧完成后发布；恢复时检查结构、簇、点电荷所有输出哈希。

验证包含：选帧末尾规则；控制别名/重复/无效步长；三斜盒原有回归；多帧跨边界完整环境、空环境及 XYZ/GJF 选择；点电荷和坐标映射；文件篡改拒绝续算；小体系真实 CPU SCF/DIPRO 的多帧独立输出及 checkpoint 复用；实际 anneal_a 轨迹第 1980/2000 帧提取和最后一帧旧 dimer 清单对照。真实材料的坐标和大体积提取文件仅留在忽略的 build 中。
