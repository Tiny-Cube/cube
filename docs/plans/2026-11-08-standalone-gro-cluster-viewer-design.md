# 独立 GRO 三维簇显示脚本

用户希望把当前本地三维视图做成独立脚本，输入 GRO，在界面调节距离阈值显示不同大小的簇。沿用本地浏览器交互方式，单个 Python 脚本内嵌网页，不依赖之前 build 目录中的抽样文件，也不调用量化引擎。

## 数据和几何

仅输入 GRO 时按连续残基记录分组，明确假设每个残基为一个完整分子，适合已核对的当前体系。GRO 本身没有成键拓扑，默认用周期最小距离生成的生成树还原分子，化学键仅按共价半径猜测显示。可选 --tpr 使用 MDAnalysis 的真实拓扑片段和化学键；脚本基本依赖只有 NumPy，TPR 模式需另安装 MDAnalysis。

GRO 定宽解析支持速度、不同坐标小数精度和 3/9 数盒子；坐标 nm 转 Å。支持非退化三斜盒、整体分子周期镜像，排除中央零镜像，保留范围内其他镜像。筛选使用包含氢的全原子最短距离严格小于阈值，不读取 core。不按原子截断邻居。零阈值只显示中央分子；零周期盒或 --no-pbc 采用非周期模式。盒子/坐标/分组不合法时给出明确错误。

按当前中央分子缓存最大可调阈值内的候选分子镜像和距离；调节阈值只过滤候选集合。每次实际返回坐标、完整分子和拓扑映射，界面中的计数对应当前成功返回的阈值，异步请求过期时不覆盖新状态。不同阈值集合应具有嵌套性。

## 界面与入口

`uv run scripts/view_clusters.py file.gro --cutoff 6 --molecule 85`。PEP 723 声明 NumPy；一份脚本可独立复制使用。可选 --tpr、--max-cutoff、--no-pbc、--port、--open。默认只监听 127.0.0.1，端口自动分配，终端输出 URL；所有文件处理在本机完成。

界面提供中央分子选择、距离滑块/数值输入、全环境/最近四邻居、氢显示、旋转/平移/缩放、重置视角和完整簇 XYZ 导出。显示 GRO 文件名、当前分组与成键来源、实际阈值、原子和镜像数、邻居距离与镜像向量；GRO-only 模式不宣称具有力场电荷或 QM/MM 参数。

## 验证

使用小型定宽 GRO 覆盖 nm/Å、速度、残基编号回绕、可变精度、三斜盒；跨边界分子还原对照预期构型；簇与独立镜像穷举比较；改变阈值验证严格边界、嵌套和完整分子。真实 anneal_a_fix.gro 的 GRO-only 还原几何与同一 GRO+TPR 模式比较，簇选择与已有冻结 MM 选择逻辑比较。浏览器检查调节阈值、切换中央分子、显示氢和导出，保留用户可操作的视图与截图。材料坐标不提交 Git。
