# 载流子主流程与静态单粒子 KMC

用户指定先固定框架、主力完善 charge-carrier，并在主段内逐项选择提取、单体、dimer、重组能和 kmc。主段内部选择的通用机制已先进入公共分支，再合并到本分支；本阶段科学实现留在 feat/charge-carrier。

## 本阶段数据流

提供两条路径：已有明确参数网络→Marcus 速率→KMC→张量/收敛诊断；或者提取清单＋本次/已有耦合 CSV＋完整四点结果→显式模型组网→同一计算路径。支持一个控制文件中的多快照独立求解，不把不同快照拼成时间相关速率。单体步骤可按主段开关省略，two-mol 内部仍按需处理必要片段。

网络保存晶胞行向量、材料坐标中的位点位置、每类载流子的位点形成自由能模型，以及每条无向周期通道的镜像、eV 耦合与成对重组能。自动产生一对定向边。不同镜像不能合并，周期自镜像允许；缺少参数与 0 耦合严格区分。提取时新存 transport_position_angstrom，避免使用已居中的单体坐标伪造位点位置；旧清单仅能从哈希核对过的原始 MD 重建。

首个物理协议是零场、静态、稀释独立单载流子，经典非绝热 Marcus。显式输入网络可给出不同位点能与成对 lambda。由量化自动组网时，位点能模型必须选 uniform 或四点绝热电子形成能近似；不同来源不能悄悄混合。成对 lambda 从供体 charged relaxation 加受体 neutral relaxation 构造，只在 forward/reverse 的等价性检查通过后使用相同对称 lambda；不通过时要求给出物理定义的成对参数，不能无依据平均。

## 采样与验收

复用通用 Engine，通过出边适配器避免每次扫描全部网络；每条轨迹分配 SHA256 派生的独立 random.Random 流，初态按零场 Boltzmann 分布采样。固定物理时刻观测，等待区间位置恒定，超过时间上限的事件不执行；事件上限截断不补造后续位移。先要求正速率图连通，显式拒绝未定义组分权重的多个连通分量。

输出未折回位移、轨迹、速率、可供原四语言 CLI 读取的 KMC1 图、中心化协方差、有限窗扩散张量与 Einstein 迁移率张量。轨迹间 jackknife 估计不确定度，对比后半窗与更晚时间窗；欠采样或事件截断报告 partial。周期回路平移秩用于识别闭合有界网络；该网络的有限时间估计和严格零长期扩散不可混淆。小图给出可逆 CTMC corrector 参考，带残差、条件数及明确的站点数限制。

## 工程范围

已有参数网络仅需 NumPy transport extra，不强制安装 PySCF 或 MDAnalysis。配置检查不导入这些科学依赖。文件哈希与实现哈希保证相同已完成/partial 结果的审计复用，输出改动拒绝复用；不做中断轨迹恢复。CPU Python 材料集合、四语言通用内核分别报告，不声称材料 GPU 或其他语言集合已完成。

有场漂移、相互作用、多载流子、动态无序、GPU 材料轨迹与一般非等价势能面的重组模型继续留为后续工作。此阶段的模型结果不等于真实材料已做完量化或获得收敛迁移率。
