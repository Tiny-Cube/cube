# 普适的 reorganization-energy 模块

用户要求该子模块服务于任何需要重组能的计算，不能把 hole/electron 或 charge-carrier
写成其核心物理定义。它既能独立运行，也可被 charge-carrier、exciton 或其他主模块调用。

## 分层契约

1. 状态：通用 A/B 标签、QM 总电荷、自旋多重度、求解方法及其 root 标识；允许两个态
   电荷和自旋相同。局域化、对称性和电子构型以后可扩展，不能只靠名称 S1 判断态身份。
2. 数据来源：直接执行量化、读取已有结构/总能量/梯度/Hessian。读取型适配器应记录原始文件、
   单位、哈希、收敛证据和能量语义，不能从激发能日志猜测绝对总能量。
3. 方法：四点、正常模、垂直梯度及能隙统计为独立算法；通过注册方法及其能力要求扩展。
4. 电子结构后端：提供针对指定态和环境的 energy / gradient / hessian / optimize 能力。
   各能力按 CPU/GPU、态求解器、嵌入模型组合预检；未实现的组合在计算开始前拒绝。
5. 环境协议：真空、冻结 MM 点电荷+LJ、未来永久多极、响应环境各自定义能量与梯度。
6. 输出及消费者：统一存四个态/几何能量、两个面上的形变能、两项之和、能隙、方法和环境。
   载流子或激子模型按各自过程定义选用参数，通用模块不擅自决定 Marcus 参数或平均两项。

## 与已确定输入分工兼容

坐标、拓扑、力场仍分离；Extended XYZ 存 QM/MM 区域和冻结标记。input 只引用文件并
指定态、算法、后端与环境协议。GDMA 文件作为独立静电数据源接入，不能与拓扑电荷重复。
首版新增态描述应使用显式的 state-a/state-b 数据，而不要求每增加 S0/S1、S1/T1、D0/D1
就新增一个互斥的 type 分支。carriers=hole,electron 保留为兼容的状态配对快捷方式。
本段记录最初设计，已发布字段见[使用手册](../site/reorganization.md)。

## 科学验证

- 两条不同曲率的可解析谐势能面：lambda_A、lambda_B 不同也能恢复正确结果。
- 交换 A/B：形变能交换，和不变，绝热能隙变号；共同能量平移不影响结果。
- 两态分别加常数：形变能不变、态间驱动能正确改变，不做隐藏能量对齐。
- 保留负形变值并诊断；物理流程使用优化/SCF 收敛和阈值判断，不能取绝对值造正数。
- 只有数学计算完成不能代表输入几何是极小点、态身份正确或外部环境一致。
- 未来态跟踪区分绝热能量排序和态特征跟踪，记录翻转/简并诊断。
- 固定环境 Hessian 中刚体运动相对环境可能有真实曲率，不能一律投影掉 3/6 个自由度。
