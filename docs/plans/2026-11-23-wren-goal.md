# Wren 验收记录

| 用户需求 | 已提供的实现与证据 |
|---|---|
| 更名和构建 | Wren 主命令、兼容旧入口、uv wheel 和源码包。顶层 CMake 组织 Python、C++、Rust、Fortran、安装、CTest 和 HTML 文档。 |
| 理论与方法选择 | 手册区分单粒子轨道、加减电子谱、位点能分布、激子与光学谱。晶体的 BZ 求积与无序超胞、紧束缚、KPM、投影、局域化、有限温度与采样误差均附有公式及参考文献。 |
| MD → PySCF → DOS | 支持 GROMACS 与 LAMMPS 提取；独立分子轨道、垂直 ΔSCF、周期 PySCF 与有效哈密顿量四条路线。实际 86 原子单体、实验萘晶胞、八帧周期萘、65,536 位点正交稀疏模型均有复算记录。 |
| GPU | RTX 5090 实测分子和周期 SCF、投影、展宽、稠密与稀疏谱。真实 100 分子载流子 KMC 在 CPU/GPU 上逐轨迹核对；两端完成约三千万次跳跃。 |
| 表面跳跃 | Tully 1/2/3、多态 LVC、距离依赖的片段模型。CPU PySCF SA-CASSCF 单重态和双重态提供解析梯度、导数耦合及相位跟踪。乙烯二聚体阳离子的局域空穴传播经步长与独立响应差分检验。 |
| 简洁图标 | 原创矢量图标已接入手册与 Python 包。 |
| 网页使用文档 | Sphinx/Furo 中文手册提供确定输入、命令、公式、示例、数值边界与一手文献的导航和搜索。GitHub 保留手册源码与构建工作流，在线预览采用用户当前账户的访问范围。 |

当前可复查材料见 [验证页](../site/validation.md)。开源工作分支为 `feat/wren`。周期超胞与开放簇、单体时间采样与体相空间无序各有对应适用范围。目标材料的环境极化、独立形貌系综、基组和活性空间收敛需按具体研究验证。激发态自动 QM/MM、GDMA 极化及周期材料的第一性原理 FSSH 可沿对应模块继续开发。
