# cube 的输运理论契约

状态：实现规划，2026-11-05。以下明确区分已存在的通用内核和待实现的材料模型。理论依据包括 [VOTCA](https://www.votca.org/xtp/transport_theory.html)、[MOMAP 公开说明](https://www.hzw.ai/momap/index)、[mcal 源码](https://github.com/matsui-lab-yamagata/mcal)、[MorphCT](https://github.com/cmelab/morphct) 与 [AMSET](https://hackingmaterials.lbl.gov/amset/)。统一符号与验收规则是 cube 的设计选择。

## 1. 物理适用域与电子片段

首批求解局域电荷在分子或电子活性链段上的非相干跳跃。位点可以是完整分子、共轭链段或经检验的局域片段，不能默认等于化学单体。需要检验电子耦合、重组能、热能及环境涨落时间尺度是否支持所选近似；单个 V/λ 阈值不构成普适适用性证明。

晶体：显式晶格、分子基元、晶格方向和周期镜像；非晶：形貌、分子映射、构象/静电无序、多份独立样本；聚合物：原子到片段映射、链/片段 ID、共价连接、链内/链间通道与分片敏感性。

强离域与动态无序可使静态 Marcus-KMC 失效。[FOB-SH 公开研究](https://www.nature.com/articles/s41467-019-11775-9)是扩展理论参照。未来离域/非绝热模块必须有自己的物理输入与验证，不能仅换一个 KMC 速率标签。

## 2. 能量、场与符号

统一 ΔG_ij = G(final) − G(initial)。载流子电荷 q = z e，电子 z = −1，空穴 z = +1；F 是电场而非电势梯度。定义：

```text
d_ij = r_j − r_i + image_ij @ H
ΔG_ij[eV] = G_j^0 − G_i^0 − z F[V/m]·d_ij[m] + ΔU_interaction[eV]
```

H 的每一行是一个晶格矢量；image 是三个整数。若显式使用静电势 φ，场贡献写作 z(φ_j−φ_i)，不再另加同一电场项。环境极化、静态电势与显式库仑必须记录来源，防止重复计数。

G^0 是该载流子形成的自由能模型。空穴形成能可由 IP 近似，电子形成能可由 −EA 近似；HOMO/LUMO 轨道能不自动等于 IP/EA，更不自动等于凝聚态位点自由能。四点法与环境处理必须写明垂直/绝热约定。

反向边 image_ji = −image_ij，d_ji = −d_ij。在静态单粒子、相同环境和成对相同重组能的模型中，ΔG_ji = −ΔG_ij。零场时应满足：

```text
k_ij / k_ji = exp[−(G_j^0 − G_i^0)/(kB T)]
π_i ∝ exp[−G_i^0/(kB T)]
```

周期系统加恒场允许有稳态电流，不能要求全图仍存在单值的平衡电势。对极小速率以 log(k_ij)−log(k_ji) 检查，避免数值下溢后除零。

## 3. 速率模型

### 3.1 经典非绝热 Marcus：首发模型

\[
k_{ij}=\frac{2\pi}{\hbar}|V_{ij}|^2
\frac{\exp[-(\Delta G_{ij}+\lambda_{ij})^2/(4\lambda_{ij}k_BT)]}
{\sqrt{4\pi\lambda_{ij}k_BT}}.
\]

V、λ、ΔG 和 kBT 采用 eV，ℏ 为 eV·s，输出 s⁻¹。要求 T>0、λ>0，V=0 返回零速率。用 log 形式求值并记录被下溢截断的通道；不暗中将无限大速率截成任意常数。

λ 包括明确定义的内、外球贡献。相同分子自交换常用四点式：

\[
\lambda_{in}=[E^q(R^0)-E^q(R^q)]+[E^0(R^q)-E^0(R^0)].
\]

异种分子/非平衡片段必须按初末态势能面定义成对参数，不能无依据平均两个单分子 λ。正反参数应满足目标热力学一致性。

耦合可先导入经过方法标记的数据；自算时保存片段轨道、重叠和正交化约定。孤立非共价二聚体的轨道分裂近似不能直接用于不等价分子或聚合物共价分片；[VOTCA 的 DIPRO/POD2 说明](https://www.votca.org/xtp/transport_theory.html#electronic-couplings)提供了相关边界。cube 将投影方法与量化后端分离。

### 3.2 Miller–Abrahams：可选模型

\[
k_{ij}=\nu_0\exp(-2r_{ij}/\xi)\min[1,\exp(-\Delta G_{ij}/k_BT)].
\]

需给定 ν₀ 与局域长度 ξ，不能将未知耦合静默替换为这个经验模型。比较其他程序时要核对它的 localization 参数是长度还是逆长度。

### 3.3 MLJ 与全量子振动速率：分阶段扩展

单个高频模、低初始振动态占据的常见 MLJ 近似为：

\[
k=\frac{2\pi|V|^2}{\hbar\sqrt{4\pi\lambda_s k_BT}}
\sum_{n\ge0}e^{-S}\frac{S^n}{n!}
\exp[-(\Delta G+\lambda_s+n\hbar\omega)^2/(4\lambda_s k_BT)].
\]

需 λ_s、ω、Huang–Rhys 因子 S、截断收敛控制；量子模与经典 λ_s 不能重复计入。多模、有限温度振动态、Duschinsky 旋转等属于后续 Franck–Condon/关联函数模块。仅有 λ、V 的旧数据不足以自动完成这类计算，MLJ 也不等于 MOMAP 全量子算法。

## 4. 周期网络与 KMC

静态网络按当前位点的可用出边计算：

\[
A_i=\sum_j k_{ij},\quad\Delta t=-\log u_1/A_i,\quad P(i\to j)=k_{ij}/A_i.
\]

A=0 是吸收/停滞，不是假造很长的一步。每条边有稳定 ID；允许同一 i,j 的多个镜像边以及 i=j 但 image≠0 的周期通道。拓扑邻居表与具体速率缓存分离；单载流子出边搜索目标 O(degree)，多载流子后续采用局部更新与总事件树。

真实材料的候选邻居由几何生成，是否有跃迁由已计算的耦合决定。π 接触阈值不能冒充完整电子网络；缺失耦合必须标成 missing，与实际计算得到的 0 区别保存。距离截断需做收敛检查。一般三斜晶胞不能直接对三个笛卡尔坐标做正交盒 round。

图连通不保证无限周期材料能导电。需检测闭合类、周期回路的净晶格平移及其张成的输运维数；封闭二聚体即使连通也应 D=0。必须显式累积未折回的位移，不能从盒内坐标差重建长程 MSD。

若速率显式连续依赖时间，等待时间应满足积分 hazard，或采用有合法上界的 thinning；不能每次冻结当前速率后声称精确。首发使用静态参数/分段恒定场，动态形貌采用明示的快照近似；将来另做含时间速率引擎。

## 5. 三种不同的迁移率协议

### 5.1 零场扩散/线性响应

\[
D_{ab}=\frac12\lim_{t\to\infty}\frac{d}{dt}
\big\langle[\Delta r_a-\langle\Delta r_a\rangle]
[\Delta r_b-\langle\Delta r_b\rangle]\big\rangle,
\qquad\mu_{ab}=\frac{|q|D_{ab}}{k_BT}.
\]

最后一式按 SI 的 J、C、m、s 计算，转换到 cm²/(V·s) 再乘 10⁴。输出完整对称张量、特征值/轴、实验方向投影。三维 trace(D)/3 只是平均值，不能代替低维或强各向异性方向迁移率。零场无漂移时协方差与未中心化 MSD 一致。

均匀初态仅适用于相应的平衡/对称模型；能量无序模型应采样平衡分布或经过足够平衡期。不能把短时斜率自动解释成长期 D。

### 5.2 有场漂移

\[
v_a=\frac{d\langle\Delta r_a\rangle}{dt},\quad
\mu_\parallel(F)=\operatorname{sgn}(q)\frac{\mathbf v\cdot\hat{\mathbf F}}{|\mathbf F|},
\quad\mu_{ab}^{lin}=\operatorname{sgn}(q)\left.\frac{\partial v_a}{\partial F_b}\right|_0.
\]

沿至少三个独立方向、小的正负场求线性响应，并检查场窗收敛。有场扩散用中心化协方差，去掉漂移的 t² 项；有限场的 D 不能普遍通过平衡 Einstein 关系转换成漂移迁移率。

### 5.3 ToF 与器件

给定注入分布、吸收面、长度 L 与沿程场，计算到达时间分布/生存概率与电流瞬态。L/(F⟨τ⟩) 只是一个明确定义的有效 ToF 估计，和 ⟨L/(Fτ)⟩不同；有色散、扩散或接触控制时不能直接解释为 bulk 迁移率。未到达轨迹需作为删失数据处理，不可丢弃。

OFET/OLED 的注入、界面、占据、库仑与空间电势改变问题本身；不能把 bulk KMC 的 μ 当成完整晶体管或器件模拟。OECT 的离子/电化学耦合若以后需要，将单独立项。

## 6. 确定性参考求解器

对静态单粒子周期网络，定义后向生成元：

\[
(Qf)_i=\sum_{i\to j}k_{ij}(f_j-f_i),\quad
Q^T\pi=0,\quad\sum_i\pi_i=1.
\]

自镜像通道在 Q 中相消，但仍贡献位移、漂移和扩散。多个闭合不可约类需要给出初态与吸收权重，不能输出一个无条件唯一平衡值。

令 b_i=Σ_j k_ij d_ij，v=Σ_i π_i b_i，解 Qχ=v−b，规范 πᵀχ=0。则对有限不可约静态 Markov 加性网络：

\[
D=\frac12\sum_{i,j}\pi_i k_{ij}
(d_{ij}+\chi_j-\chi_i)(d_{ij}+\chi_j-\chi_i)^T.
\]

矩阵残差、概率归一性、非负性、规范残差、D 对称性/半正定性均为验收项。一般非对称率网络必须用适合非对称稀疏系统的求解器，不能直接调用当前基于对称 Laplacian 的 eigh。

cube 当前脚本只实现了对称网络、均匀平衡分布的特例，不是通用有场/无序求解器。当前与 mcal 的数值对照同样只证明这个共同适用域。

## 7. 多载流子与统计

多载流子首先支持显式占据排斥，再增加相互作用。静态单粒子对称网络的均匀 π、经典 Einstein 简式与独立粒子基准不可直接套用到有限浓度相互作用体系。电导/迁移率计算需标明实际载流子密度与测量协议。

库仑会改变远端位点能，不能只更新刚移动粒子的几条边而保持其他速率缓存不变；从小体系全量重算基准开始，再验证截断/长程算法。开放电极与周期电荷背景应采用各自相容的电势约定。

固定物理时间网格观测；等待区间位置分段常数，跨越时间上限的事件不执行；占据按停留时间加权。采样误差通过独立轨迹/分块或适当 bootstrap 评估，不能把同一条 MSD 曲线的时间点当独立样本。形貌误差与轨迹误差分别报告。无扩散平台、强陷阱、删失、欠采样应输出 unconverged/partial 状态和原因。

随机数保留便携参考流作跨语言回归；生产模式增加经过检验的发生器/独立流分配，保存 seed、stream、轨迹 ID、软件与算法版本。改变采样算法后可要求分布一致，而不是强行要求消耗不同随机数的算法逐轨迹一致。
