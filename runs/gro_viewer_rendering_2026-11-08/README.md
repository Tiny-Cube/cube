# 大簇旋转绘制优化验证

真实 GRO：`anneal_a_fix.gro`，中央分子 99，阈值 30 Å，显示氢：30014 个原子、31759 条键、348 个环境分子镜像。材料坐标、浏览器截图与基准输入仅留在本地忽略的 build 目录。

原版本每帧创建全部原语对象、排序、逐条提交绘图；优化后缓存可见集合/半径/键、连续缓冲投影并分组批量绘制。大簇拖动/滚轮期间显示外围抽样点，保留中央完整分子，停止后恢复全部细节。中央分子最后绘制突出显示；这是分组线框示意，未提供实体遮挡。

## 同数据 JS 对照

基线为 `a00e8d7` 的内嵌脚本，新旧脚本在 Node.js VM 及同一空 Canvas 实现下运行。预热 5 次，25 次测量，每次改变旋转角度并重画；包含显示氢。**以下不包含 Canvas 栅格化/合成，不能作为真实浏览器帧率或整帧延迟。**

| 模式 | JS 中位耗时 ms | JS P95 ms | stroke/帧 | fill/帧 | 绘制原子数 |
|---|---:|---:|---:|---:|---:|
