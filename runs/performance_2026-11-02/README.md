# 四语言 KMC 计算速度实测

2026-11-02，本机单核串行测试。下面均为 5 次重复的中位数；每项另有一次完整预热，语言运行顺序交错。所有计算一致性检查通过。

硬件：Intel(R) Core(TM) i7-1065G7 CPU @ 1.30GHz；固定到逻辑 CPU 0。

软件：Python 3.13.11；c++ (GCC) 16.2.1 20260810；GNU Fortran (GCC) 16.2.1 20260810；rustc 1.94.1 (e408947bf 2026-03-25)。

C++ 和 Fortran 使用 `-O3`，Rust 使用 release / opt-level=3，未启用 fast-math。Fortran 性能构建不启用编译器运行时边界检查，但保留库内数值合法性检查。Python 直接使用 uv 创建的虚拟环境，不计 uv 启动。

## 结论与范围

在此次真实体系的纯计算测试中，C++ 与 Fortran 的中位速度接近，且测量范围重叠；Rust 在这两个负载中次之，Python 较慢。两态与反应网络中的排序和倍数不同。CSV 格式化会显著改变整体耗时，因此不能用 CLI 耗时直接代表 KMC 内核速度。

这些结果比较本仓库当前实现，而非语言本身的性能上限。未锁定 CPU 主频、睿频、温度或其他系统活动；报告保留波动范围。没有并行运行测速任务，也没有在计时期间编译。物理时间与计算耗时是不同量；这里比较的是墙钟耗时。

每个纯计算样本核对事件数、最终模拟时间、事件索引校验和、位置和模型状态；CLI 样本核对事件数与模拟时间。已有跨语言轨迹测试提供更细的逐事件验证。
