# 模型 FSSH 验证（2026-11-09）

范围：`feat/surface-hopping` 分支，Python/NumPy 实固定正交基模型引擎。无实际材料结构、量化任务或 GPU 测试。此目录只记录合成／公开模型，不包含 MD 数据。

## 独立量子散射参照

运行 `scripts/validate_surface_hopping.py --trajectories 128`，完整数字见 [reference.json](reference.json)。

Tully 1，质量 2000，初始高斯波包位置均值 -8、标准差 1，动量均值 20、标准差 0.5（原子单位）。FSSH 从同一最小不确定波包的 Wigner 分布采样，初始绝热下态；远离耦合区时与纯 diabatic 0 波包一致到可忽略误差。随机种子 29101，核步长 1 au，电子子步 4，无去相干。

量子参考是独立实现的 diabatic FFT split-operator，直接构造原论文势能，不调用 FSSH provider、NAC 或传播程序。周期区间 [-35,35)，传播 2200 au，粗网格 2048/步长 1 与细网格 4096/步长 0.5 对照。最终中心区概率小于 5e-21，波包已离开耦合区，边界未触及。

| 右侧透射末态 | 细网格量子概率 | FSSH 计数 / 128 | FSSH 概率 | 差值 / 二项标准误 |
| --- | ---: | ---: | ---: | ---: |
| adiabatic 0 | 0.507007814 | 63 | 0.4921875 | -0.3354 |
| adiabatic 1 | 0.492992176 | 65 | 0.5078125 | +0.3354 |

128 条全部向右退出，没有 unfinished。量子参考加密后最大通道变化 9.59e-7。FSSH 最大总能量漂移 6.76e-7 Hartree、hop 瞬间能量误差 3.13e-17 Hartree、电子范数误差 3.17e-13。该脚本含量子参考与串行轨迹的总时间约 194 s，不是语言或 GPU 性能比较。

该结果支持此高动量双态工况的实现，但误差条约为 0.044，不能当作百分之一精度证明。还没有覆盖低动量反射、模型 2/3 的完整散射概率曲线、材料迁移率和 GPU 等价性。FSSH 与精确量子动力学本身也不完全等价。
