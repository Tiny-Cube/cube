# 单载流子 KMC 同机计时

本次在 Xeon Platinum 8380、NVIDIA RTX 5090 上顺序执行 Wren 的 Python 和 CUDA 后端。每个设置各运行一次，CuPy 在单元测试中已加载并编译过内核。墙钟时间包含速率组装、轨迹、精确静态网络参考、采样统计及写盘。输入为 frame 2000 的 100 个分子、550 对耦合；两个方向共 1,100 条通道。300 K、零外场、均匀位点能，空穴与电子的重组能分别为 0.310715784506、0.348854567167 eV。源码版本为 `2d561b7849321ba9038a25b6fe94603384b1ca11`。

| 每类轨迹数 | 时长 | 总事件数 | Python CPU | RTX 5090 | CPU/GPU | 空穴/电子相对 95% 区间范数 |
|---:|---:|---:|---:|---:|---:|---:|
| 256 | 2 ns | 1,525,803 | 8.501 s | 0.577 s | 14.7× | 0.423 / 0.456 |
| 2,048 | 5 ns | 30,479,173 | 160.634 s | 1.418 s | 113.3× | 0.159 / 0.160 |

程序从归档输入重建晶胞通道，并逐条核对方向、位移和 Marcus 速率。每条轨迹独立生成初态和随机流，同一编号在两端复用相同的 MT19937 种子。全部 51 个采样时刻的三维位移与逐轨迹事件数在两端完全一致。对较大运行，两类载流子各保留前三条轨迹，合计 46,411 条事件记录，事件顺序、位移与时间均相同。较大运行的晚期拟合窗口变化为 0.070（空穴）和 0.096（电子），与区间诊断均达到 0.25 的设定阈值。该诊断衡量固定静态网络上的采样精度。实际材料还涉及位点能无序和多个构型的取样。

```bash
uv sync --locked --extra transport-cuda13
uv run --no-sync python scripts/validate_material_gpu_kmc.py build/material-small
uv run --no-sync python scripts/validate_material_gpu_kmc.py build/material-large --trajectories 2048 --duration 5e-9
```

两个 `*-trajectories.json` 保存每次运行的扩散迁移率估计和网络精确迁移率张量；`diagnostics.json` 保存设备版本、采样误差和拟合窗口敏感性。每次复算请使用新的输出目录。
